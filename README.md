# ☀️ Solar Tracker

A microcontroller-based dual-axis solar tracking system designed to continuously orient a solar panel toward the Sun, maximizing energy capture throughout the day.

This repository contains the firmware, control algorithms, and supporting code for an autonomous solar tracker. Unlike simulation-only projects, this work was validated on a **fully constructed physical prototype** that successfully tracked the Sun under real outdoor conditions.

---

## Features

- 🌞 Automatic dual-axis solar tracking
- 🧭 Continuous sun position calculation and tracking
- ⚙️ Real-time motor control
- 🔋 Optimized panel orientation for maximum solar exposure
- 💻 Embedded firmware implementation
- 🛠️ Designed to run on low-cost hardware

---

## Project Overview

Traditional fixed solar panels only operate at peak efficiency for a limited portion of the day. This project improves energy harvesting by actively adjusting the panel orientation so that it remains perpendicular to incoming sunlight.

The tracker continuously determines the desired panel orientation and commands the motors to reposition the system whenever necessary.

The project focuses on:

- Embedded system development
- Motion control
- Sensor integration
- Real-time control algorithms
- Renewable energy applications

---

## Hardware Prototype

One of the main goals of this project was not only to develop the software but also to validate it on real hardware.

A complete physical solar tracker was designed and constructed, including:

- Mechanical tracking structure
- Motorized actuation system
- Electronic control hardware
- Embedded controller
- Solar panel mounting assembly

The prototype was successfully tested outdoors and demonstrated reliable autonomous tracking of the Sun throughout the day.
